# Docker Compose for Cadenway

Inspect the owning checkout's Compose files, service boundaries, ports and health checks; ops owns shared infrastructure and local stack composition. Keep internal services private and use the repository's documented environment examples without reading secrets. Validate the relevant Compose configuration with the repository's prescribed command when the files and tools exist. Do not deploy or start a server-side stack unless expressly authorized.

Consult the official documentation for the version actually used: https://docs.docker.com/compose/.
