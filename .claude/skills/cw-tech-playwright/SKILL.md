# Playwright for Cadenway

Inspect the owning project's browser-test configuration and the `cw-e2e-playwright` skill when present. Use reliable, accessible locators and isolate test data; test the requested user-visible flow and meaningful failure states. Start only services the task authorizes, use project-provided commands and fixtures, and report whether the stack, browsers, and tests actually ran. The Playwright MCP can help inspect a flow but does not replace executable regression tests when needed.

Consult the official documentation for the version actually used: https://playwright.dev/docs/intro.
