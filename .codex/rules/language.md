# Language

Everything written in this repository is in **English**: source code, identifiers, comments and
docblocks, documentation, agent prompts, rules, skills, hook messages, test titles, commit messages,
branch names, pull request titles and descriptions.

**User-facing copy is French**, taken word for word from the mockup (Cadenway is a French product).
Keep UI strings out of logic: one place per feature, so a later `@angular/localize` extraction is
mechanical. Text quoted from the mockup (screen names such as `App.dc.html`, labels) stays as it is,
inside code formatting.

No emojis. The conversation with the user follows the user's language.
