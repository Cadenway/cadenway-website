# Angular for Waypoint

First read the owning project's Angular rules and existing skills, including `wp-angular22-conventions`, `wp-signal-forms`, or `wp-website-sections` when present. Check the project's actual Angular version and use its local Angular MCP when available; a global fallback may be a different version. Follow the project's component, accessibility, localization, routing, and rendering conventions. Consume `@waypoint/ui` and `@waypoint/api-client` where applicable; keep the static-prerendering requirements of the website. Run the relevant component, build, or browser checks.

Consult the official documentation for the version actually used: https://angular.dev/overview.
