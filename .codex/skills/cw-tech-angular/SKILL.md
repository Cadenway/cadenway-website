# Angular for Cadenway

First read the owning project's Angular rules and existing skills, including `cw-angular22-conventions`, `cw-signal-forms`, or `cw-website-sections` when present. Check the project's actual Angular version and use its local Angular MCP when available; a global fallback may be a different version. Follow the project's component, accessibility, localization, routing, and rendering conventions. Consume `@cadenway/ui` and `@cadenway/api-client` where applicable; keep the static-prerendering requirements of the website. Run the relevant component, build, or browser checks.

Consult the official documentation for the version actually used: https://angular.dev/overview.
